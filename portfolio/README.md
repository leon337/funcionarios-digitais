# Portfólio comercial

Site estático responsivo para apresentar serviços de implantação de funcionários digitais.

## Antes de divulgar
Edite js/config.js:
- brandName: marca definitiva.
- whatsappNumber: código do país + DDD + número, somente dígitos (ex.: 5511999999999).
- instagramUrl e facebookUrl: URLs reais dos perfis.
- contactEmail: e-mail comercial, se houver.

Não divulgue o endereço em campanhas antes de configurar pelo menos um canal real de contato. Não coloque segredos no frontend.

## Teste local
Abra index.html em um navegador ou sirva esta pasta com qualquer servidor HTTP estático.
